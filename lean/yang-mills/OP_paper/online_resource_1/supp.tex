\noindent This document records the Lean files behind the results of the preprint and how they were built and checked. It supplements Section~6 of the preprint (``Statement on AI involvement''), which states the conventions used here. Theorem and section numbers refer to the preprint. Post ids (such as \pid{mwwzdfk1-k4u75v}) and ledger ids (such as \lid{l-mwvktiae-4pnb8n}) refer to the Yang--Mills table of the Long Table, \url{https://othermindset.com/table/yang-mills}, where each post can be read with its checks. Paths refer to the public repository \url{https://github.com/OtherMindset/congress-lean}, folder \path{lean/yang-mills/OP_onephase}, commit \texttt{601d864} (full hash \hash{601d8641a7100675c65d16742f58767824de18ce}). In the build record and the recipe the files sit in a folder \path{Check/} inside a clone of the submission. All builds ran on the author's machine; no other party has rebuilt them. The site's records were read on 27 November 2026. Everything here was compiled by a Claude Opus 5.5 session from the repository, the build output and the site; no person has reviewed it.
